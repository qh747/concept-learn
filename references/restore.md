# 恢复存档（references/restore.md）

> 本文件为 SKILL.md 的恢复流程细节下沉，由 SKILL.md 通过 context pointer 引用。agent 在恢复存档时加载本文件。

## 恢复触发与流程

**触发方式**：

- **显式命令**：`/concept-learn 恢复` → 列出存档供选择；`/concept-learn 恢复 <主题>` → 匹配主题并确认后恢复。
- **自然语言**：用户说"继续上次学的 X"、"恢复 X 进度"、"接着学 X" 等。

### 查找与恢复

**用户指定了主题**：

1. 查找 `.concept-learn/` 下对应主题 slug 子目录。
2. 若找到 → **显式命令需向用户确认后恢复**；自然语言直接恢复。
3. 若未找到 → 告知无该主题存档，询问是否新建学习。

**用户未指定主题**（如"继续上次的学习"）：

1. 扫描 `.concept-learn/` 下所有子目录。
2. 单个存档 → 直接恢复；多个存档 → 列出主题与进度供选择；无存档 → 询问是否新建。

## 恢复后行为

1. 读取存档的 frontmatter 获取结构化数据，读取正文获取已讲解的阶段内容。
2. 向用户简要汇报：
   - 主题、学习目标导向、解释详略、输出模式
   - 本次采用的模板（若存档含 `template` 字段）
   - 当前进度（阶段标题与状态）
   - 告知将从第 N 阶段继续
3. 按 `stage_status` 优先级规则（见 references/save-system.md）确定续讲阶段，从该阶段继续讲解：
   - `in_progress` 从中断处续讲
   - `not_started` 从头讲

## 恢复时跳过执行前提问

恢复存档时**跳过**执行前提问（3 个必答问题）与模板加载流程，直接按存档中已记录的目标导向/详略/自检/输出模式/模板继续学习。这是因为这些参数已在存档中固化，无需再次询问。
