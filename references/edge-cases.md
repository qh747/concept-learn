# 边界与异常处理（references/edge-cases.md）

> 本文件为 SKILL.md 的边界与异常处理细节下沉，由 SKILL.md 通过 context pointer 引用。agent 在遇到异常输入/多主题/无效选择等情况时加载本文件。

## 主题提取规则

1. **显式命令带参数**：`/concept-learn <参数>`，参数中可能包含自然语言。
   - 如果参数包含触发关键词（"教我"、"我想学"、"带我掌握"），用关键词后面的内容作为主题。
   - 如果不含关键词，直接以参数全部内容作为主题。
   - 示例：
     - `/concept-learn 我想学 python` → 主题 = python
     - `/concept-learn 我想学 python 的 async 原理` → 主题 = python async 原理
     - `/concept-learn React` → 主题 = React
2. **自然语言触发**：从句子中提取主题，规则同上。
3. **多主题**：检测到多个主题（如"我想学 React 和 Vue"），回复"你提到多个主题，请先选择一个开始学习"，让用户选择。
4. **slug 化**：保存时转小写、空格转连字符、去除特殊字符。

## 执行前提问的异常处理

### 用户一次性回答多个问题

执行前提问要求一次只问一个问题。若用户一次性回答了多个问题：

1. **只取第一个答案**，忽略其他。
2. 回复："收到，已记录。接下来回答第二个问题：..."

### 无效选择处理

用户回复的序号不在选项范围内（如选项 1/2/3，用户输入 4）：

1. 提示："无效选项，请重新选择（输入序号 1/2/3，或回"默认"）。"
2. 连续 3 次输入无效选项 → 退出整个 concept-learn 学习流程，回复："已超过重试次数，concept-learn 已退出。"

## 大纲确认的判定

**视为确认**：用户明确表达肯定（如"可以"/"没问题"/"开始"/"确认"/"就这样"等肯定性短语）。

**不视为确认**的情况：
- 犹豫（"我想想"/"等一下"）
- 提出具体调整（"第 2 阶段改一下"）
- 岔开话题

以上均不视为确认，需继续追问。

**硬性规则**：未得到用户对大纲的明确确认，绝不允许进入讲解阶段。

## 用户岔开话题的处理

- 用户提出非学习相关的问题 → 正常回答该问题。
- 回答完后回到学习中，提示："回到学习中，刚刚我们讲到 [当前阶段名]……"。
- 不中断学习状态，`current_stage` 保持不变，不触发退出提示或存档询问。

## 用户询问进度

用户可随时说"刚刚讲到哪了"、"之前教到哪了"、"现在学到哪了"等，AI 回复当前阶段信息：

"当前在第 [N] 阶段（[阶段标题]），[已完成/进行中]。"

## 跳过阶段

用户可说"第 3 阶段我已会，跳过" → 将该阶段标记为 `completed`，`current_stage` 跳到下一个未完成阶段的编号。

可复习被跳过的阶段，复习时重新完整讲解该阶段内容，完成后回到当前进度，**不改变 `current_stage`**。

## 复习已学阶段

用户可说"复习一下第 1 阶段" → 重新讲解该阶段内容，复习完后回到当前进度继续。

**复习不改变 `current_stage`**。
