# 系统设计模板

## 推荐大纲骨架

1. **题型与解法框架**：系统设计题的常见题型与通用解题框架（需求澄清 → 容量估算 → 架构草图 → 深入组件 → 取舍）。
2. **核心子系统拆解**：按经典子系统（接入、存储、计算、缓存、消息）讲清各部分职责与选型空间。
3. **典型场景实战**：选 2-3 个高频场景（短链/Feed/秒杀/限流）走完整框架。
4. **关键取舍点**：CAP/一致性/分区/扩展性等面试官爱深挖的决策点。
5. **表达与控场**：如何在限定时间内讲清架构、主动引导追问、暴露亮点。

## 各阶段讲解结构指导

- 第 2 阶段用分层架构图打底，每个子系统标注"它扛什么指标、常见选型有哪些"。
- 第 3 阶段每场景走"需求 → 估算 → 草图 → 瓶颈 → 优化"五步，配 Mermaid 架构图。
- 第 4 阶段每个取舍点用"选项 A vs B → 各自代价 → 不同规模下怎么选"展开。

## 自检题方向

倾向"给定一个场景，请画出架构草图并说明各层选型理由"的开放题，重思路而非标准答案。
