# 应试导向模板索引

> 本索引用于关键词匹配。agent 读取本表，按用户原始表述中出现的 keywords 命中模板；唯一命中 → 提示采用该模板；多命中/零命中 → 列出候选让用户选。用户自增模板需在此追加一行。

| name | scenario | keywords | description |
|---|---|---|---|
| interview-faq | 面试高频 | 面试、八股、面试题、高频考点、常问、背、必问 | 覆盖面试高频问答，主打能讲清 |
| system-design | 系统设计 | 系统设计、设计题、场景题、架构题、开放题 | 以开放设计题为主，重思路与权衡 |
| certification | 认证考试 | 认证、考试、证书、考纲、考题、单选、选择题 | 围绕固定考纲与标准答案组织 |

## 匹配细则

- 关键词对大小写不敏感，对中英文混合表述同样匹配。
- 多命中/零命中时直接列候选让用户选，不自动合并。
- 未命中时列出全部 3 个模板供用户选；仍不选 → 提示可自定义模板后退出流程。
