# 应用导向模板索引

> 本索引用于关键词匹配。agent 读取本表，按用户原始表述中出现的 keywords 命中模板；唯一命中 → 提示采用该模板；多命中/零命中 → 列出候选让用户选。用户自增模板需在此追加一行。

| name | scenario | keywords | description |
|---|---|---|---|
| quick-start | 快速上手 | 快速、上手、入门、开始、quick start、getting started、跑起来、用起来 | 最短路径跑通最小可用示例 |
| hands-on-project | 实战项目 | 实战、项目、做一个、搭建、从零、动手、实践、练手 | 以一个完整小项目贯穿各阶段 |
| api-usage | API 用法 | api、用法、接口、调用、sdk、方法、参数、怎么用 | 系统梳理 API 表面与调用模式 |
| troubleshooting | 问题排查 | 排查、踩坑、报错、问题、bug、坑、调试、常见错误、疑难 | 围绕常见问题与排错路径组织 |
| tech-selection | 技术选型 | 选型、对比、哪个好、比较、vs、区别、选谁、取舍 | 以对比与决策视角组织 |
| performance-tuning | 性能调优 | 性能、调优、优化、加速、慢、瓶颈、压测、吞吐、延迟 | 围绕性能瓶颈定位与优化手段 |

## 匹配细则

- 关键词对大小写不敏感，对中英文混合表述同样匹配。
- 当用户表述命中多个模板的 keywords 时，**不要自动合并**，直接列出所有候选并问用户选其一。
- 当用户表述未命中任何模板时，列出全部 6 个模板供用户选；若用户仍不选，提示可自定义模板后退出流程。
