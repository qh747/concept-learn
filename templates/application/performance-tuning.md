# 性能调优模板

## 推荐大纲骨架

1. **性能模型与指标**：吞吐、延迟、资源占用，及它们之间的权衡关系。
2. **测量与基线**：如何建立基线、用什么工具观测，避免无依据优化。
3. **瓶颈定位流程**：从指标异常到具体代码/资源的定位方法。
4. **典型优化手段**：按层级（算法/并发/缓存/IO/调度）展开常用手段。
5. **验证与回归**：优化后如何验证、防回退、权衡副作用。

## 各阶段讲解结构指导

- 第 2 阶段给出一份**可执行的观测清单**。
- 第 3 阶段用 Mermaid 流程图固化"先测哪里再看哪里"的顺序。
- 第 4 阶段每条手段含"适用前提、典型收益、代价"。

## 自检题方向

倾向"给出一段性能现象/指标，请定位可能的瓶颈层级并说明排查顺序"的情景题。
