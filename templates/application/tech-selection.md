# 技术选型模板

## 推荐大纲骨架

1. **需求与约束**：明确要选什么、约束是什么、不能选什么。
2. **候选概览**：列出候选及其定位、社区、成熟度。
3. **逐维对比**：性能、易用性、生态、维护成本、迁移成本、风险等维度横向对比。
4. **典型场景适配**：在不同场景下各候选的优劣。
5. **决策建议**：给定常见前提的推荐取向与折中点。

## 各阶段讲解结构指导

- 第 3 阶段用对比表格 + 简短点评，不堆形容词。
- 第 4 阶段用场景矩阵或决策树（Mermaid）。
- 对每个候选给一句"它适合谁、不适合谁"。

## 自检题方向

倾向"给定一组约束，请选出更合适的候选并说明理由"的判断题。
