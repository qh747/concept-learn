# 问题排查模板

## 推荐大纲骨架

1. **问题分类地图**：把常见问题按症状/阶段分类，给出"先看哪类"的入口。
2. **高频问题集**：每条含触发条件、典型报错、根因、解决步骤。
3. **诊断方法论**：定位问题的一般流程：复现 → 缩小范围 → 假设 → 验证。
4. **工具与观测**：日志、断点、profiler、内置诊断命令。
5. **预防与回溯**：如何写法/约束/测试避免再次踩坑。

## 各阶段讲解结构指导

- 第 2 阶段每条以"报错原文 → 根因 → 修复"三段式呈现。
- 第 3 阶段给一个**可操作的决策树**（ASCII 或 Mermaid 流程图）。
- 引用真实报错片段，不臆造。

## 自检题方向

倾向"给出一段报错/现象，请定位根因并给出修复步骤"的情景题。
