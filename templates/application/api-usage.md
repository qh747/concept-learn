# API 用法模板

## 推荐大纲骨架

1. **API 全景**：分类一览，先建立地图，再不迷路。
2. **核心 API**：最高频/最基础的若干方法，逐一走通签名、参数、返回、异常。
3. **协作 API**：与核心 API 配合的辅助类、回调、配置。
4. **典型组合**：把多个 API 串成常见任务流。
5. **边界与陷阱**：线程模型、资源释放、副作用、版本差异。

## 各阶段讲解结构指导

- 每个方法**先签名后示例再说明**，保持一致结构便于查阅。
- 第 4 阶段用 Mermaid 序列图展示 API 调用顺序与数据流。
- 第 5 阶段建"坑表"，每条含触发条件、症状、规避方法。

## 自检题方向

倾向"给定需求选哪个 API""这段代码会抛什么异常"的场景判断题。
