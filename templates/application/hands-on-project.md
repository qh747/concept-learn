# 实战项目模板

## 推荐大纲骨架

1. **项目目标与产物定义**：明确项目要做什么、最终长什么样、验收标准。
2. **技术栈与骨架**：依赖、目录结构、初始化。
3. **核心功能实现**：分步骤实现主功能，每步可运行。
4. **完善与打磨**：错误处理、边界、可读性、必要测试。
5. **复盘与扩展**：可改进点、可扩展方向、与真实项目的差距。

## 各阶段讲解结构指导

- 每阶段产物可运行或可观察，避免纯理论阶段。
- 第 3 阶段按功能切片，**一片一切**：一个功能从无到有后立刻自检/确认再进入下一片。
- 代码块标注"加在哪里""替换什么"，避免用户迷路。
- 每阶段结尾给"当前应可见的结果"作为对账点。

## 自检题方向

倾向"为什么这一步要这样做""如果换成 X 实现会怎样"的判断题，而非记忆题。
