# 演进历史模板

## 推荐大纲骨架

1. **起点与背景**：所处时代背景、要回应的旧问题。
2. **初代形态**：最早的版本长什么样、解决了什么、留下什么遗憾。
3. **关键转折**：几次重要演进，每点含驱动力、变化、新矛盾。
4. **现状解读**：今天形态如何被历史累积塑成，残留了哪些历史包袱。
5. **趋势与展望**：基于脉络推断可能的方向，谨慎给出。

## 各阶段讲解结构指导

- 第 3 阶段用时间线（Mermaid 或 ASCII）标出转折点。
- 每次转折讲清"驱动力 → 决策 → 新矛盾"，避免编年流水账。
- 区分"历史原因"与"现在还成立的原因"，不要用过去合理化现在。

## 自检题方向

倾向"为什么会有第 N 次转折""X 特性是哪个时期为解决什么而引入的"的脉络题。
