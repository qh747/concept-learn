# 理解导向模板索引

> 本索引用于关键词匹配。agent 读取本表，按用户原始表述中出现的 keywords 命中模板；唯一命中 → 提示采用该模板；多命中/零命中 → 列出候选让用户选。用户自增模板需在此追加一行。

| name | scenario | keywords | description |
|---|---|---|---|
| intuition | 建立直觉 | 直觉、本质、为什么这样、为什么存在、设计为什么、背后逻辑 | 先建立直觉式理解，再串接原理 |
| how-it-works | 工作原理 | 原理、怎么工作、运行机制、内部流程、流程、机制 | 完整讲清"它如何运转"的整体流 |
| source-code | 源码学习 | 源码、源代码、内核、实现、读源码、源码走读 | 以源码为线索逐层拆解实现 |
| internal-mechanism | 内部机制 | 内部机制、深入机制、底层、内部结构、组件协作 | 聚焦内部组件协作与数据流 |
| design-ideas | 设计思想 | 设计、设计思想、设计哲学、为什么这么设计、思想 | 提炼设计哲学与权衡取舍 |
| evolution-history | 演进历史 | 演进、历史、发展、怎么来的、前世今生、来龙去脉 | 用历史脉络串起概念演进 |

## 匹配细则

- 关键词对大小写不敏感，对中英文混合表述同样匹配。
- 当用户表述命中多个模板时，直接列出候选让用户选，不自动合并。
- 未命中时列出全部 6 个模板供用户选；仍不选 → 提示可自定义模板后退出流程。
