# 源码学习模板

## 推荐大纲骨架

1. **代码地图**：源码目录/模块布局、入口文件、阅读路线建议。
2. **入口走读**：从主入口/对外 API 进入，逐层下钻到核心。
3. **核心数据结构**：支撑实现的关键结构、不变量、命名约定。
4. **关键算法/流程**：最体现设计的关键路径，配源码片段精读。
5. **扩展点与边界**：哪里可插拔、哪里是历史包袱、版本差异点。

## 各阶段讲解结构指导

- 引用源码片段要标**文件:行号**或提交锚点，避免脱钩。
- 每段精读遵循"读完代码 → 它在做什么 → 为什么这么做"三步。
- 大段源码先给摘要再贴关键片段，不整段堆砌。

## 自检题方向

倾向"指出这段代码在做什么、为什么这样写"的精读题，而非默写源码。
